🚀 PROJECT DEVELOPMENT

🚀 Project Title: Campus Complaint Tracker

📝 Project Problem Statement

Students often face problems related to classrooms, laboratories, washrooms, college facilities and other campus services. Reporting these complaints and tracking their status can be difficult.

The aim of this project is to develop a system that allows students to submit complaints and track their progress easily.

📌 Project Description

Campus Complaint Tracker is a student-friendly application designed to make complaint management easier in colleges.

Students can submit complaints, view their complaint status and receive updates. The administrator can view complaints and update their status.

✨ Key Features

- Students can register and submit complaints.
- Students can track complaint status.
- Admin can view all submitted complaints.
- Admin can update complaint status.
- Complaints can be categorized based on issues.
- Simple and user-friendly interface.

🛠️ Technologies Used

- Programming Language: Java
- IDE: Eclipse
- Concepts: Object-Oriented Programming
- Additional Technologies: To be decided during development.
